SC4SAP Web PoC · v0.5.3 · globals.css 기준

한 가지 잉크, 표면의 단계, 은은한 그림자

PoC 웹앱의 색상·타이포·모션·컴포넌트 규칙을 한 장에 모았습니다. 이 페이지의 모든 색은 PoC의 CSS 변수 그대로이며, 오른쪽 위 토글로 라이트/다크를 바로 비교할 수 있습니다. sc4sap.dev를 PoC 톤으로 맞출 때 기준 자료로 쓰세요.

디자인 원칙

PoC의 팔레트는 의도적으로 "한 가지 색"입니다. 아래 다섯 가지가 모든 결정의 기준입니다.

잉크는 하나

강조색은 #2f3540(쿨 그레이 잉크) 하나뿐. 흰색이 아닌 모든 값은 표면 단계이거나 이 잉크의 투명도입니다.

깊이는 표면 단계로

배경 → 레일 → 패널 순으로 한 단계씩 차이를 두고, 카드는 아주 옅은 그림자로 띄웁니다. 색으로 구분하지 않습니다.

상태는 굵기와 채움으로

실행 중 = 채운 잉크, 대기 = 외곽선, 끝남 = 흐리게. 색상(Hue)은 연결 상태(ok/warn/bad)에만 예외적으로 씁니다.

다크는 토큰 교체만

다크 테마는 표면·잉크 토큰만 바꿉니다. 컴포넌트 규칙에 색을 직접 쓰지 않기 때문에 가능합니다.

한 폰트로 한글·영문

Pretendard가 한글과 라틴을 같은 굵기·기준선으로 처리합니다. 제목만 Schibsted Grotesk.

색상 토큰

칩 색상은 현재 선택된 테마의 실제 값입니다. 토글을 바꾸면 같이 바뀝니다.

표면 (Surface)

잉크 (Ink) — 텍스트·아이콘·채움

선 (Line)

상태 (Status) — 유일한 유채색 예외

그림자 · 딤 (Shadow / Scrim)

라이트 / 다크 대응표

다크는 같은 디자인을 뒤집은 것입니다. 잉크는 순백이 아닌 #e6e9ee — 라이트에서 #2f3540이 흰 바탕과 갖는 대비 관계를 그대로 유지합니다. 상태색은 11px 대문자로도 쓰이므로 다크에서 밝게 올립니다.

토큰라이트다크용도

테마 선택 규칙: 사용자가 고르면 <html data-theme="light|dark">, 고르지 않으면 prefers-color-scheme. 미디어쿼리는 반드시 :root:not([data-theme="light"])로 감싸야 "다크 OS + 라이트 선택"이 뒤집히지 않습니다.

타이포그래피

본문 기본 14px / 1.55, 루트 자간 -0.03rem(Pretendard 보정). 제목은 추가로 -0.02em. 코드·숫자 정렬이 필요한 곳은 모노 + 자간 normal.

그림자

--card-shadow

카드를 바탕에서 살짝 띄움. 여러 장이 나란히 있어도 한 면처럼 읽히는 정도.

--composer-shadow

입력창. 포커스 시 --composer-shadow-focus로 한 단계 진하게.

모달·가이드 창. rgba(var(--shadow-rgb), .35) — 다크에서 shadow-rgb는 검정.

sc4sap.dev 적용 가이드

sc4sap.dev는 아이보리·앰버 팔레트이고, PoC는 그 사이트에서 타이포와 모션만 가져왔습니다(팔레트는 의도적으로 가져오지 않음). 사이트를 PoC 톤으로 맞출 때의 매핑입니다.

체크리스트

  1. 컴포넌트 CSS에서 hex/rgb 직접 사용 제거 → 전부 토큰 참조로.
  2. :root에 라이트, [data-theme="dark"]와 @media (prefers-color-scheme: dark) :root:not([data-theme="light"]) 두 곳에 다크.
  3. 채운 요소 위 글자는 흰색 고정 대신 --on-ink (다크에서 흰 버튼 위 흰 글자 방지).
  4. 그림자는 rgba(var(--shadow-rgb), a) — 다크에서 자동으로 검정.
  5. 모달 딤은 --scrim (라이트 잉크 35% / 다크 검정 62%).
  6. 본문 폰트 Pretendard + 자간 -0.03rem, 제목 Schibsted Grotesk -0.02em, 코드 IBM Plex Mono.
  7. 트랜지션: 색 620ms, 상태 260ms, 누름 140ms, 이징 cubic-bezier(0.16,1,0.3,1). prefers-reduced-motion 존중.
  8. 포커스 링은 모든 컨트롤 공통 outline: 2px solid var(--ink); outline-offset: 2px.
