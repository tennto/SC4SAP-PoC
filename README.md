# SC4SAP Web PoC

A browser front end for the [SuperClaude for SAP (sc4sap)](https://github.com/babamba2/superclaude-for-sap) Claude Code plugin, run headlessly through the Claude Agent SDK.

## Status

This proof of concept is under active development and is not yet at a state we share externally. Progress details are therefore not published here.

More information will be released in November 2026.

## Versioning

Releases are tagged `vMAJOR.MINOR.PATCH` and the version is raised with every pull request. Current baseline: **0.2.1**.
